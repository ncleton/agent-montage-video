# Style « charte »

L'habillage sobre de la charte Rossini Energy : fond clair, fenêtre arrondie, rouge Rossini `#e3342f` pour les
étiquettes, l'onde des clics et les puces, sous-titres sur bande sombre, police Montserrat. Aucun personnage.

Il sert aux tutoriels d'interface quand le bon demande `brief.style = "charte"` (vidéo pour un client, page
publique). Son habillage est dans `kit.json` ; il n'a pas d'images.
